# ספר דרשות הרב חיים דרעי שליט״א

ספר שנבנה מתוך 83 הדרשות המצולמות שבאתר (service-3473.ai.studio), מסודר לפי שערים (נושאים), דרשה לכל פרק.

## מבנה התיקייה

| נתיב | תוכן |
|---|---|
| `data/drashot.json` | רשימת 83 הדרשות: מזהה יוטיוב, כותרת מקורית, תאריך עברי, שער |
| `data/site_order.txt` | הרשימה כפי שהיא מופיעה באתר, עם התאריכים |
| `data/raw_stats.json` | גודל התמלול הגולמי של כל דרשה (לבקרת איכות) |
| `drashot/<id>.md` | הטקסט הערוך של כל דרשה |
| `build/` | סקריפטים לבניית הספר |
| `output/` | הקבצים המוכנים (Word ו-PDF) |
| `../sefer/index.html` | הספר הדיגיטלי לאתר |

## סימונים בקובצי הדרשות

| סימון | משמעות |
|---|---|
| `[[12:31]]` | תחילת פסקה, והזמן שלה בסרטון |
| `## כותרת` | כותרת משנה שהוסיף העורך |
| `{{במדבר יג, ב}}` | מראה מקום שהוסיף העורך |
| `[?]` / `[?12:31]` | מילים לא ברורות בהקלטה (מקושר לרגע בסרטון) |
| `[מילה]` | השלמה של העורך למילה או אותיות שנבלעו בהקלטה |
| `[מן הקהל: …]`, `[שירה]`, `[קטע לא תומלל 60:10]` | הערות על המתרחש בשיעור |

כלל העריכה: מתקנים רק שגיאות זיהוי ברורות של התמלול האוטומטי, ומוסיפים פיסוק ופסקאות. לא מוסיפים, לא משמיטים, לא מסכמים ולא מנסחים מחדש.

## בנייה

```bash
python3 -I book/build/make_metadata.py      # רשימת הדרשות והשערים (משתמש ב-build/themes_draft.py)
python3 -I book/build/build_web.py          # sefer/index.html
python3 -I book/build/build_pdf.py          # book/output/sefer.pdf (Chromium דרך Playwright)
python3 -I book/build/build_docx.py         # book/output/sefer.docx
python3 -I book/build/qa.py                 # בקרת איכות
```
