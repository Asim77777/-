# ספר דרשות הרב חיים דרעי שליט״א

ספר שנבנה מתוך 83 הדרשות המצולמות שבאתר (service-3473.ai.studio), מסודר לפי שערים (נושאים), דרשה לכל פרק.
כרגע בנויות 3 דרשות דוגמה; שאר הדרשות ייבנו אחרי אישור הדוגמה.

## דרך העבודה

1. **עריכה** – התמלול האוטומטי של יוטיוב נערך מלשון דיבור ללשון כתב, לפי `STYLE.md`: כל רעיון, סיפור, משל ודוגמה נשמרים בסדרם; מילות מילוי, חזרות ושיחות צד מושמטות.
2. **מקורות** – כל פסוק ומאמר חז״ל הושווה לנוסחו בספריא (sefaria.org.il), ובספר מופיע נוסח ספריא. מקור שלא אותר אינו מושלם מהזיכרון; הוא נרשם ב-`data/sources_report.json`.
3. **ניקוד מלא** – בעזרת המנקד של דיקטה (`dicta-il/dictabert-large-char-menaked`), עם בדיקה אוטומטית שלא השתנתה אף מילה, ותיקוני עורך ב-`data/niqqud_fixes.json`. הפסוקים מנוקדים כנוסח המסורה מספריא.
4. **הגהה** – hspell על דברי הרב; כל מילה שהוא מסמן נבדקה ונרשמה ב-`data/hspell_reviewed.txt`. כתיב מלא לפי האקדמיה, וכתיב מסורתי במונחי קודש (כהן, אהל, מצוה).
5. **השלמות** – מקומות שלא נשמעו (`[?]`) נאספים לדף השלמה (`fill/hashlama.html`, פורסם כארטיפקט), והתשובות נכתבות אל הטקסט.

| `front/` | ההקדמה, שמות השערים והכותרות |
| `STYLE.md` | מדריך העריכה והכתיב |
| `transcript/` | נוסח הדיבור של דרשות הדוגמה (לפני העריכה לכתב) |
| `data/drashot.json` | 83 הדרשות: מזהה יוטיוב, כותרת, תאריך עברי, שער |
| `data/sefaria_raw/` | הטקסטים שנשלפו מספריא |
| `data/sources_report.json` | דוח המקורות |
| `data/niqqud_fixes.json` | תיקוני ניקוד ידניים (מילה שלמה) |

| `build/` | סקריפטים לבניית הספר |

| `../sefer/` | הספר הדיגיטלי (index.html ועמוד לכל דרשה) |

## סימונים בקובצי הדרשות

| סימון | משמעות |
|---|---|
| `[[12:31]]` | תחילת פסקה, והזמן שלה בסרטון |
| `## כותרת` | כותרת משנה שהוסיף העורך |
| `⟦Genesis 18:23\|טקסט⟧` | ציטוט; מוחלף בנוסח ספריא המנוקד ומקבל הערת שוליים |
| `{{Bava Batra 16a}}` | מראה מקום (הערת שוליים) |
| `{{!טקסט חופשי}}` | הערת שוליים בנוסח חופשי |
| `{{?תיאור}}` | מקור שלא אותר בספריא (לא מודפס; נרשם בדוח) |
| `[?12:31]` | מקום שלא נשמע בהקלטה |
| `[מילה]` | השלמת העורך |
| `[מן הקהל:]` | דברים מפי השומעים |

## בנייה

```bash
book/build/all.sh          # הכול: ספריא ← ניקוד ← PDF, Word, אתר, דף השלמה ← בקרת איכות
```

שלבים בודדים: `sefaria.py`, `niqqud.py <in> <out>`, `build_tex.py`, `build_docx.py`, `build_web.py`, `build_fill.py`, `qa.py` (כולם עם `python3 -I`).
דרושים: XeLaTeX עם polyglossia, גופני Culmus (Taamey Frank CLM, Keter Aram Tsova, Keter YG) ו-Noto Rashi Hebrew, hspell, Node עם `docx`, ו-Python עם `transformers==4.57.6`, `torch`, `segno`, `fonttools`.

הגופנים באתר (`sefer/fonts`) הם תת-קבוצות של גופני Culmus מאת יורם גנת, ברישיון GPL-2 עם חריגת גופנים.
