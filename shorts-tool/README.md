# Shorts Studio

כלי מקומי שהופך סרטון יוטיוב ל־1 עד 5 שורטס אנכיים (9:16) עם כתוביות צרובות, וכולל עורך כתוביות מלא. הכול רץ על המחשב שלך, בחינם ובלי מפתחות API.

## מה צריך להתקין פעם אחת

1. **Python 3.10 ומעלה** – <https://www.python.org/downloads/> (ב־Windows לסמן "Add Python to PATH").
2. **ffmpeg**
   - Windows: `winget install Gyan.FFmpeg`
   - Mac: `brew install ffmpeg`
   - Linux: `sudo apt install ffmpeg`
3. מומלץ: **Node.js** (<https://nodejs.org>) – יוטיוב דורש אותו לחלק מהסרטונים.

## הפעלה

- Windows: לחיצה כפולה על `run.bat`
- Mac / Linux: `./run.sh`

בהפעלה הראשונה מותקנות התלויות (כמה דקות), ואז נפתח הדפדפן בכתובת <http://localhost:8000>.
בפעם הראשונה שמתמללים יורד גם מודל התמלול (כ־1.6GB למודל העברי).

## איך משתמשים

1. מדביקים קישור ליוטיוב (או בוחרים קובץ וידאו מהמחשב), בוחרים כמה שורטס רוצים ולוחצים **צור שורטס**.
2. הכלי מוריד את הסרטון, מתמלל אותו עם תזמון לכל מילה, ובוחר את הקטעים החזקים ביותר. לכל קטע מוצג ציון ולמה הוא נבחר.
3. בעורך:
   - **עיצוב** – 9 סגנונות מוכנים, 28 גופנים עבריים, גודל, צבעים, קו מתאר, צל, תיבת רקע, הדגשת המילה הנאמרת, אנימציות, מיקום (אפשר גם לגרור את הכתובית על התצוגה), מספר מילים בשורה. אפשר לשמור סגנון משלך ולהחיל על כל השורטס.
   - **כתוביות** – תיקון טקסט, תזמון, פיצול, מיזוג ומחיקה של שורות.
   - **קטע** – קיצור/הארכה של הקטע, מסגור (מילוי וחיתוך או התאמה עם רקע מטושטש), כותרת בראש הסרטון.
   - **ייצוא** – קובץ MP4 ‏1080×1920 עם הכתוביות בפנים, וקובץ SRT.

## טיפים

- **תמלול איטי?** בלי כרטיס מסך של NVIDIA המודל העברי האיכותי איטי (בערך כאורך הסרטון ואף יותר). ב"הגדרות מתקדמות" אפשר לבחור מודל "מהיר" – פחות מדויק אבל מהיר בהרבה, ואת הטעויות מתקנים בלשונית "כתוביות".
- **יוטיוב מבקש התחברות?** ב"הגדרות מתקדמות" בוחרים את הדפדפן שבו אתה מחובר ליוטיוב, או מעלים את קובץ הווידאו ישירות.
- **הורדה נכשלת בלי סיבה ברורה?** יוטיוב משתנה לעיתים קרובות. לעדכן: `.venv/bin/pip install -U yt-dlp` (ב־Windows: `.venv\Scripts\pip install -U yt-dlp`).
- העריכות נשמרות אוטומטית בדפדפן; הקבצים עצמם נשמרים בתיקייה `data/` ואפשר למחוק פרויקטים ממסך הבית.

השתמש בכלי רק עם סרטונים שלך או כאלה שיש לך רשות להשתמש בהם.

## למפתחים

```
app/download.py     yt-dlp + ffprobe
app/transcribe.py   faster-whisper, תזמון ברמת מילה
app/highlights.py   דירוג ובחירת קטעים (היוריסטיקה מקומית)
app/subtitles.py    style JSON -> ASS
app/render.py       ffmpeg: חיתוך, 9:16, צריבת כתוביות
static/             ממשק (HTML/CSS/JS ללא build)
fonts/              גופנים ברישיון OFL + fonts.json (מדדים להתאמת התצוגה לייצוא)
tests/              pytest
```

הרצת בדיקות: `.venv/bin/pip install pytest && .venv/bin/python -m pytest tests`
